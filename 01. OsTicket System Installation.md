# osTicket — Local Installation Guide

 > A step-by-step guide to installing **osTicket v1.18.4** on a local **XAMPP** environment using Apache, MySQL, PHP, and phpMyAdmin.

---

 ## 📌 Overview

 This guide walks through the complete local installation of **osTicket** on Windows using **XAMPP Control Panel v3.3.0**.

 The installation covers:

 - Downloading osTicket
- Configuring the XAMPP environment
- Installing osTicket under `htdocs`
- Enabling required PHP extensions
- Creating the osTicket database and database user
- Creating the osTicket configuration file
- Configuring the helpdesk
- Creating the administrator account
- Completing the osTicket installation

---

 ## 🧰 Requirements

 Before starting, install or have access to the following:

 | Requirement | Version / Configuration |
| --- | --- |
| Operating System | Windows |
| XAMPP | v3.3.0 |
| PHP | 8.0 or greater |
| Apache | Included with XAMPP |
| MySQL | Included with XAMPP |
| Browser | Chrome / Firefox / Edge |
| osTicket | v1.18.4 |

---

 # 1\. Download osTicket

 Download osTicket from the official website:

 - **Official Website:** https://osticket.com/download/
- **GitHub Releases:** https://github.com/osTicket/osTicket/releases

 For this installation, we will use:

```
osTicket-v1.18.4.zip
```

 Download the ZIP archive and save it somewhere convenient.

---

 # 2\. Start XAMPP

 Open:

```
XAMPP Control Panel v3.3.0
```

 Start the following services:

```
Apache
MySQL
```

 Both services should display a **Running** status.

```
Apache  → Running
MySQL   → Running
```

 > **Important:** Apache and MySQL must be running before accessing the local osTicket installation.

---

 # 3\. Extract osTicket

 Extract:

```
osTicket-v1.18.4.zip
```

 Inside the extracted directory, you should see the following main directories:

```
osTicket-v1.18.4/
├── scripts/
└── upload/
```

---

 # 4\. Prepare the osTicket Directory

 Create the following directory:

```
C:\xampp\htdocs\osTicket
```

 ## Move `scripts` into `upload`

 Move the `scripts` directory into the `upload` directory:

```
upload/
└── scripts/
```

 Next, move **all files and directories inside `upload`** into:

```
C:\xampp\htdocs\osTicket\
```

 After the files have been moved, the resulting structure should look similar to:

```
C:\xampp\htdocs\osTicket\
├── api\
├── assets\
├── include\
├── scp\
├── scripts\
├── setup\
├── bootstrap.php
└── ...
```

 Once you have verified that everything was copied successfully, the original `upload` directory is no longer required and can be removed.

---

 # 5\. Open osTicket

 Open your browser and navigate to:

```
http://localhost/osTicket/
```

 The osTicket installer should redirect you to:

```
http://localhost/osTicket/setup/
```

 The installer will now check your PHP environment.

---

 # 6\. Verify PHP Requirements

 The osTicket installer performs an environment check.

 You should see required components such as:

```
PHP v8.0 or greater
MySQL extension for PHP
```

 For example:

```
✅ PHP v8.0 or greater - (8.2.4)       
✅ MySQL extension for PHP - module loaded 
```

 The installer will also display recommended PHP extensions.

---

 ## PHP Extension Status

 Initially, some extensions may be disabled:

 | Extension | Purpose | Initial Status |
| --- | --- | --- |
| GD | Image processing | ❌ |
| IMAP | Mail fetching | ❌ |
| XML | XML API | ✅ |
| XML-DOM | HTML email processing | ✅ |
| JSON | Application performance | ✅ |
| Mbstring | String handling | ✅ |
| Phar | Plugins and language packs | ✅ |
| Intl | Localization | ❌ |
| APCU | Performance | ❌ |
| OPcache | PHP performance | ❌ |

 Some of these extensions are optional, but enabling the recommended extensions provides better compatibility and functionality.

---

 # 7\. Enable PHP Extensions

 Open the **XAMPP Control Panel**.

 Under **Apache**, click:

```
Config
```

 Open the PHP configuration file:

```
php.ini
```

 You can also find it at:

```
C:\xampp\php\php.ini
```

---

 ## 7.1 Enable GD

 Find:

```
;extension=gd
```

 Change it to:

```
extension=gd
```

---

 ## 7.2 Enable Intl

 Find:

```
;extension=intl
```

 Change it to:

```
extension=intl
```

---

 ## 7.3 Enable IMAP

 Find:

```
;extension=imap
```

 Change it to:

```
extension=imap
```

---

 ## 7.4 Enable FTP

 Find:

```
;extension=ftp
```

 Change it to:

```
extension=ftp
```

---

 ## 7.5 Enable OPcache

 Find:

```
;zend_extension=opcache
```

 Change it to:

```
zend_extension=opcache
```

---

 ## 7.6 Save the Configuration

 Save the file using:

```
Ctrl + S
```

 Close the configuration file.

---

 # 8\. Restart XAMPP Services

 The PHP configuration will not take effect until Apache is restarted.

 In the XAMPP Control Panel:

 1. Stop **Apache**.
2. Stop **MySQL**.
3. Start **Apache**.
4. Start **MySQL**.

 The final state should be:

```
Apache  → Running
MySQL   → Running
```

---

 # 9\. Verify PHP Extensions

 Return to:

```
http://localhost/osTicket/setup/
```

 Refresh the page.

 The extension status should now look similar to:

 | Extension | Status |
| --- | --- |
| PHP 8.0 or greater | ✅ |
| MySQL extension | ✅ |
| GD | ✅ |
| IMAP | ✅ |
| XML | ✅ |
| XML-DOM | ✅ |
| JSON | ✅ |
| Mbstring | ✅ |
| Phar | ✅ |
| Intl | ✅ |
| APCU | ❌ |
| OPcache | ✅ |

 > **Note:** APCU may remain disabled at this stage. It is primarily a performance enhancement and can be configured later.

 Once the required checks are satisfied, click:

```
Continue
```

---

 # 10\. Create the osTicket Configuration File

 After clicking **Continue**, the installer should open:

```
http://localhost/osTicket/setup/install.php
```

 You may see an error indicating that the osTicket configuration file is missing.

 To fix this, navigate to:

```
C:\xampp\htdocs\osTicket\include\
```

 Locate:

```
ost-sampleconfig.php
```

 Rename it to:

```
ost-config.php
```

 The final path must be:

```
C:\xampp\htdocs\osTicket\include\ost-config.php
```

---

 # 11\. Refresh the Installer

 Return to:

```
http://localhost/osTicket/setup/install.php
```

 Refresh the page.

 The configuration-file error should now be resolved.

 You should see the main osTicket installation form.

---

 # 12\. Create the MySQL Database

 Before completing the osTicket installation form, create the database.

 Open:

```
http://localhost/phpmyadmin/
```

---

 # 13\. Create the osTicket Database User

 In phpMyAdmin:

 1. Select **User Accounts**.
2. Click **Add user account**.

 Create the following user:

 | Setting | Value |
| --- | --- |
| Username | `osticket` |
| Host name | `localhost` |
| Password | `password@123` |
| Retype password | `password@123` |

---

 ## Database Permissions

 Under **Database for user account**, select:

```
✅ Create database with same name and grant all privileges
```

 Also enable:

```
✅ Grant all privileges on wildcard name (username\_%)
```

 Under **Global privileges**, select:

```
Check all
```

 Then click:

```
Go
```

---

 # 14\. Verify the Database

 The user should now be created successfully.

 Because the database was configured to use the same name as the user, you should also have a database named:

```
osticket
```

 Your database configuration is now:

```
Database Host: localhost
Database Name: osticket
Database User: osticket
```

---

 # 15\. Configure osTicket

 Return to:

```
http://localhost/osTicket/setup/install.php
```

 You can now complete the installation form.

---

 # 16\. System Settings

 Under **System Settings**, enter your helpdesk information.

 Example:

 | Setting | Value |
| --- | --- |
| Helpdesk URL | `http://localhost/osTicket/` |
| Helpdesk Name | `osTicket System` |
| Default Email | `admin@osticket.com` |
| Primary Language | `English (United States)` |

 > **Note:** These email addresses are examples for a local installation. Use real email addresses when configuring a production system.

---

 # 17\. Create the Administrator Account

 Under **Admin User**, create the primary administrator account.

 Example:

 | Field | Value |
| --- | --- |
| First Name | `IT` |
| Last Name | `Support` |
| Email Address | `it@osticket.com` |
| Username | `itsupport` |
| Password | `password@123` |
| Retype Password | `password@123` |

 This account will be used to access the osTicket administrator interface.

 > ⚠️ **Security:** Never use `password@123` as a production password. Use a strong, unique password.

---

 # 18\. Configure Database Settings

 Under **Database Settings**, enter:

 | Setting | Value |
| --- | --- |
| MySQL Table Prefix | `ost_` |
| MySQL Hostname | `localhost` |
| MySQL Database | `osticket` |
| MySQL Username | `osticket` |
| MySQL Password | `password@123` |

 The final configuration should be:

```
MySQL Table Prefix: ost_
MySQL Hostname:     localhost
MySQL Database:     osticket
MySQL Username:     osticket
MySQL Password:     password@123
```

---

 # 19\. Install osTicket

 Review all the configuration values.

 If everything is correct, click:

```
Install Now
```

 The installer will configure the application and create the required database tables.

---

 # 20\. Installation Completed

 After the installation completes, you should see a **Congratulations** message.

 This confirms that osTicket has been successfully installed and configured.

 🎉 **Your local osTicket installation is complete!**

---

 # 21\. Access the osTicket Portal

 ## User / Ticket Portal

 Open:

```
http://localhost/osTicket/
```

 Open:

```
http://localhost/osTicket/scp/
```

 # 🔧 Troubleshooting

 ## PHP Extension Is Still Disabled

 If an extension continues to show ❌:

 1. Open XAMPP.
2. Go to **Apache → Config → PHP (php.ini)**.
3. Verify that the extension is uncommented.
4. Save `php.ini`.
5. Stop Apache.
6. Start Apache again.
7. Refresh the osTicket setup page.

---

 ## Configuration File Missing

 Verify that this file exists:

```
C:\xampp\htdocs\osTicket\include\ost-config.php
```

 If it does not exist, rename:

```
ost-sampleconfig.php
```

 to:

```
ost-config.php
```

---

 ## Database Connection Error

 Verify all database values:

```
Hostname: localhost
Database: osticket
Username: osticket
Password: password@123
```

 Also confirm that the `osticket` MySQL user has sufficient privileges.

---

 ## Apache Does Not Start

 Another application may already be using Apache's port.

 Check the XAMPP Control Panel logs and verify the configured Apache ports.

 Common ports include:

```
HTTP:  80
HTTPS: 443
```

---

 ## MySQL Does Not Start

 Check whether another MySQL/MariaDB service is already running.

 The default MySQL port is commonly:

```
3306
```

 Check the XAMPP logs if MySQL fails to start.

 # 🔐 Security Considerations

 This guide is designed for a **local development/testing environment**.

 Before using osTicket in production:

 - Use strong, unique passwords.
- Do not use `password@123`.
- Use a real email address.
- Configure SMTP properly.
- Enable HTTPS.
- Keep PHP updated.
- Keep osTicket updated.
- Protect `ost-config.php`.
- Do not expose phpMyAdmin to the public internet.
- Remove or disable installation functionality after setup when appropriate.
- Do not commit credentials to GitHub.

---

 # 🚫 Do Not Commit Credentials

 Never commit passwords or other secrets to a GitHub repository.

 For example, do not commit:

```
password@123
```

 or real database credentials.

 If you store local configuration files in the project, consider adding them to `.gitignore`:

```
.env
.env.*
*.local.php
config.local.php
```
