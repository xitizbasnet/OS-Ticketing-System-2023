# 🎫 How to Raise a Support Ticket in osTicket

 This guide explains how to create a new support ticket using the **osTicket** web interface.

 > \[!NOTE\]\
>  The following example uses the sample contact information and ticket details provided below.

 ## 1\. 🌐 Open osTicket

 1. Open **Google Chrome**.
2. Enter the following URL in the address bar:

```
localhost/osTicket/
```

 3. Press **Enter** to open the osTicket application.

---

 ## 2\. 🆕 Open a New Ticket

 The first method is to:

 1. Click the blue button labeled **"Open a New Ticket"**.

---

 ## 3\. 📝 Fill In the Ticket Details

 After selecting **"Open a New Ticket"**, fill in the required information.

 ### Contact Information

 | Field | Example |
| --- | --- |
| **Email Address** | `test@osticket.com` |
| **Full Name** | `test` |
| **Phone Number** | `+977-9812365478` |
| **Ext** | `***` |

### Help Topic

 Set the **Help Topic** to:

```
General Inquiry
```

 ### Ticket Details

 Enter the following information:

 **Please describe your issue:**

```
please describe your issue
```

 **Issue Summary:**

```
system not working
```

---

 ## 4\. 🎫 Create the Ticket

 After completing the required ticket information:

 1. Review the entered details.
2. Click the button labeled **"Create Ticket"**.

---

 ## 5\. ✅ Confirm Ticket Creation

 After the ticket has been created successfully, a success alert message will appear:

 > **"Support ticket request created"**

 This message confirms that the support ticket request was successfully submitted.

---

 ## 💡 Best Practices

 - Verify the **email address** and **phone number** before creating the ticket.
- Select the most appropriate **Help Topic** for the issue.
- Provide a clear and descriptive **Issue Summary**.
- Include sufficient information in **Ticket Details** so the IT support team can understand and troubleshoot the issue.
- Always confirm that the **"Support ticket request created"** success message appears after submission.
