# Create a Custom Queue for Current-Month Open Tickets in osTicket

 This guide explains how to create a **custom ticket queue** in osTicket that displays tickets with an **Open** status and a **Create Date** within the **current month**.

 The custom queue will be named **Open Ticket Current Month** and will appear under the **Tickets \> Open** submenu alongside the existing ticket queue options.

 >  **Application:** osTicket\
>  **Feature:** Custom Queues\
>  **Queue Name:** `Open Ticket Current Month`

---

 ## 🎯 Objective

 Create a custom queue with the following criteria:

 | Configuration | Value |
| --- | --- |
| **Queue Name** | Open Ticket Current Month |
| **Parent Queue** | Open |
| **Search Criteria** | Create Date → Period → This Month |
| **Expected Location** | Tickets → Open |

After the queue is created, the **Open Ticket Current Month** option should be available under the **Open** ticket submenu.

---

 ## Prerequisites

 Before beginning, ensure that:

 - You have administrator access to the osTicket Staff Control Panel.
- You have permission to create and modify ticket queues.
- osTicket is installed and accessible through the local web server.
- You can access the ticket management interface.

---

 # Step 1: Open osTicket Settings

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/scp/setting.php
```

 3. Sign in with an administrator account if prompted.

---

 # Step 2: Open Ticket Settings

 1. From the osTicket Staff Control Panel, go to:
    **Settings \> Tickets**
2. Locate the **Queue** menu option.
3. Open **Queue**.

---

 # Step 3: Create a New Queue

 The Queue page allows you to create custom queues based on specific ticket search criteria.

 1. Click the **Add New Queue** icon.
2. Configure the new queue using the following values.

 ### Queue Name

 Enter:

```
Open Ticket Current Month
```

 ### Parent Queue

 Select:

```
Open
```

 ### Queue Search Criteria

 Configure the search criteria as follows:

 1. Select or tick:
    ☑ **Create Date**
2. Set the condition to:

```
Period → This Month
```

 The queue should therefore identify tickets that meet the configured **Create Date → Period → This Month** criteria under the **Open** parent queue.

---

 # Step 4: Create the Queue

 After entering the required configuration:

 1. Review the queue name.
2. Verify that **Open** is selected as the parent queue.
3. Confirm that the search criteria is:
    **Create Date → Period → This Month**
4. Click **Create**.

 If the queue is created successfully, osTicket will display the following success alert message:

 > ✅ **"Successfully updated Open Ticket Current Month"**

---

 # Step 5: Verify the Custom Queue

 After successfully creating the queue, verify that it appears in the ticket interface.

 1. Open a new browser tab or navigate to:

```
localhost/osTicket/scp/tickets.php
```

 2. Locate the **Tickets** menu.
3. Click **Tickets**.
4. Look at the dropdown options under the **Open** submenu.

 ### Before Creating the Custom Queue

 The **Open** submenu contains:

```
Open
├── Open/Answered
└── Overdue
```

 ### After Creating the Custom Queue

 The **Open** submenu should contain:

```
Open
├── Open/Answered
├── Overdue
└── Open Ticket Current Month
```

 The newly created **Open Ticket Current Month** queue is now available for staff to quickly view open tickets created during the current month.

---

 # ✅ Final Configuration

 The completed queue configuration should be:

```
Queue Name:
Open Ticket Current Month

Parent Queue:
Open

Queue Search Criteria:
☑ Create Date
  └── Period
      └── This Month
```

 After creation:

```
Tickets
└── Open
    ├── Open/Answered
    ├── Overdue
    └── Open Ticket Current Month
```

 ## 💡 Best Practices

 - **Use descriptive queue names:** Choose names that clearly explain what tickets the queue contains.
- **Use parent queues logically:** Assign the custom queue to the appropriate parent category, such as **Open**.
- **Keep search criteria simple:** Use only the criteria required to identify the intended tickets.
- **Verify after creation:** Always check the **Tickets** menu to confirm that the custom queue appears in the expected location.
- **Test the queue:** Create or identify a ticket that meets the criteria and verify that it appears in the custom queue.
- **Review periodically:** Confirm that the queue continues to return the expected tickets as the month changes.

 > **Note:** The **This Month** period is dynamic. As the calendar month changes, the queue should use the current month when evaluating the configured date criteria.

 > ⚠️ **Warning:** Before deploying a custom queue in a production environment, verify that the search criteria return the intended tickets. Incorrect criteria can result in tickets being omitted from the queue or appearing unexpectedly.
