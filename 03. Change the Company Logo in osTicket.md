# 03\. Change the Company Logo in osTicket

 ## Overview

 This procedure explains how to change the **company logo** in the osTicket system, remove the default `setup` directory for security purposes, and verify that the updated logo appears on both the **Admin Dashboard** and **Admin Login Portal**.

 > 🎯 **Objective:** Replace the existing company logo with a new custom logo and verify that the change is reflected throughout the osTicket administration interface.

---

 ## Prerequisites

 Before starting, ensure that:

 - Google Chrome is installed.
- The osTicket application is running through XAMPP.
- You have administrator access to osTicket.
- A new company logo file is available on the local computer.
- You have access to the osTicket installation directory.

---

 ## Step 1: Open the osTicket User Interface

 1. Open **Google Chrome**.
2. Enter the following URL:

   ```
   localhost/osTicket/
   ```
3. The **Welcome Dashboard** of osTicket will open.

 > 💡 **Note:** The Welcome Dashboard is also known as the **User Interface (UI)**.

---

 ## Step 2: Log In to the Admin Portal

 To access the osTicket Admin Portal:

 1. Open Google Chrome.
2. Navigate to:

   ```
   localhost/osTicket/scp/login.php
   ```
3. Enter the administrator credentials:
    | Credential | Value |
   | --- | --- |
   | **Username** | `itsupport` |
   | **Password** | `password@123` |
4. Click **Login**.

 > ✅ **Success:** You have successfully logged in to the osTicket Admin Portal.

---

 ## Step 3: Navigate to the Company Logo Settings

 To change the company logo:

 1. Navigate to:
    **Settings \> Company \> Logo**
2. Under **Custom Logo**, locate the **Upload a new logo** option.
3. Click **Choose File**.
4. Select the new company logo from your computer.

 > 💡 **Tip:** Use an appropriately sized company logo that is optimized for web display.

---

 ## Step 4: Save the New Logo

 After selecting the logo:

 1. Click **Save Changes**.
2. Select the radio button for **Both**.
3. Click **Save Changes** again.

 > ✅ **Success:** The new company logo has been uploaded and configured.

---

 ## Step 5: Verify the Logo on the Dashboard

 Return to the osTicket dashboard.

 The newly uploaded company logo should now be visible on the dashboard.

 > ✅ **Verification:** The company logo has been successfully changed in the osTicket dashboard.

---

 ## Step 6: Review the Security Alert

 At the top of the dashboard, you may see the following security alert:

 > ⚠️ **Security Alert**
>
>  **"Please take a minute to delete setup directory (.../setup) for security reasons."**

 This message indicates that the osTicket `setup` directory still exists and should be removed after installation/configuration.

---

 ## Step 7: Delete the osTicket `setup` Directory

 Navigate to the osTicket installation directory:

```
C:\xampp\htdocs\osTicket\
```

 Inside this directory, locate the folder:

```
setup
```

 Delete the **`setup`** folder.

 > ⚠️ **Warning:** Delete the `setup` directory only after the osTicket installation and required configuration have been completed. The directory is removed to prevent unauthorized access to installation functionality.

---

 ## Step 8: Refresh the osTicket Dashboard

 After deleting the `setup` folder:

 1. Return to the browser.
2. Refresh the page.
3. Verify that the URL has changed to:

   ```
   localhost/osTicket/scp/index.php
   ```
4. Click **Logout**.

---

 ## Step 9: Perform a Hard Refresh

 After logging out:

 1. Open Google Chrome.
2. Press:

   ```
   Ctrl + F5
   ```

 This performs a **hard refresh** of the browser page and clears the cached version of the page being displayed.

---

 ## Step 10: Verify the Logo on the Admin Login Portal

 Open Google Chrome and navigate to:

```
localhost/osTicket/scp/login.php
```

 The updated company logo should now be visible on the **Admin Login Portal**.

 > ✅ **Success:** The company logo has been successfully changed and is now displayed on the osTicket login portal.

---

 ## Step 11: Log In Again

 Use the administrator credentials:

 | Credential | Value |
| --- | --- |
| **Username** | `itsupport` |
| **Password** | `password@123` |

 Click **Login**.

---

---

 ## Best Practices

 - 🔐 **Remove the setup directory:** Once installation and configuration are complete, remove the `setup` directory as recommended by osTicket.
- 🖼️ **Use an optimized logo:** Keep the logo appropriately sized and optimized for web use.
- 💾 **Keep a backup:** Maintain a backup of the original logo and relevant configuration before making changes.
- 🔄 **Use a hard refresh:** If the old logo continues to appear, use **Ctrl + F5** to force the browser to reload the latest version.
- 🔑 **Protect administrator credentials:** Do not expose production administrator passwords in public GitHub repositories or shared documentation.
- 🧪 **Verify after changes:** Always verify the updated logo from both the dashboard and login portal.

 > ⚠️ **Security Note:** The administrator credentials are retained because they were included in the original procedure. For production documentation, credentials should be replaced with a secure reference to your organization's password manager or secret-management system.
