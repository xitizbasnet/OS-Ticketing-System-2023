# Remove the “Not Yet Registered? Create an Account” Option from the osTicket Login Page

 This guide explains how to remove the **“Not Yet Registered? Create an Account”** option from the osTicket customer login page.

 The configuration is performed by disabling the requirement for users to register and log in before creating tickets. After saving the changes, the customer registration option will no longer be displayed on the login page, while the **“I'm an agent \- Sign In Here”** option remains available.

 >  **Application:** osTicket\
>  **Feature:** User Registration and Authentication\
>  **Expected Result:** Remove the customer registration option from the login page

---

 ## 🎯 Objective

 ### Before Configuration

 The osTicket login page displays two options on the right side:

 1. **Not yet registered? Create an account**
2. **I'm an agent \- Sign In Here**

 ### After Configuration

 The login page should display only:

 1. **I'm an agent \- Sign In Here**

---

 # Step 1: Verify the Current Login Page

 Before making any configuration changes, verify the current login page.

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/login.php
```

 3. On the login dashboard, look at the options displayed on the right side of the page.

 You should see:

```
1. Not yet registered? Create an account
2. I'm an agent - Sign In Here
```

 > **Note:** The **“Not yet registered? Create an account”** option is associated with the customer registration functionality.

---

 # Step 2: Open osTicket System Settings

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/scp/settings.php
```

 3. Sign in with an administrator account if prompted.
4. Go to:
    **Settings**

---

 # Step 3: Configure Authentication Settings

 In the Settings page, configure the following values.

 ## General Settings

 ### Name Formatting

 Set:

```
First Last
```

 ### Avatar Source

 Set:

```
Gravatar / Mystery Man
```

---

 ## 🔐 Authentication Settings

 Configure the authentication settings as follows.

 ### Registration Required

 Make sure the following option is **disabled**:

```
☐ Require registration and login to create tickets
```

 This is the key setting for removing the customer registration option from the login page.

 ### Registration Method

 Set:

```
Private — Only agents can register users
```

 ### Password Policy

 Set:

```
— All Active Policies —
```

 ### User Excessive Logins

 Configure:

```
4 failed login attempt(s) allowed before a lock-out is enforced
2 minutes locked out
```

 ### User Session Timeout

 Set:

```
30
```

 ### Authentication Token

 Enable:

```
☑ Enable use of authentication tokens to auto-login users
```

 ### Client Quick Access

 Enable:

```
☑ Require email verification on "Check Ticket Status" page
```

 # Step 5: Save the Changes

 After verifying the configuration:

 1. Scroll to the bottom of the settings page.
2. Click:

 > **Save Changes**

 3. Wait for the settings to be saved successfully.

---

 # Step 6: Verify the Login Page

 After saving the configuration:

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/login.php
```

 3. Review the login dashboard.

 The login page displayed:

```
1. Not yet registered? Create an account

```

 ### After

 The login page should now display:

```
1. I'm an agent - Sign In Here
```

 The **“Not yet registered? Create an account”** option should no longer be displayed.

 ## 💡 Best Practices

 - **Verify before and after:** Always check the login page before changing the configuration and again after saving.
- **Use administrator access:** Authentication and registration settings should only be modified by authorized administrators.
- **Test in a non-production environment:** Validate authentication changes before applying them to production.
- **Review registration requirements:** Disabling the registration requirement changes how customers interact with the ticketing system.
- **Check session settings:** Ensure the session timeout is appropriate for your organization's security requirements.
- **Monitor failed logins:** Keep account lockout protection enabled to reduce the risk of repeated unauthorized login attempts.

 > **⚠️ Warning:** Authentication settings affect how users access the osTicket system. Incorrect configuration can change the way customers and agents authenticate or access tickets. Always verify the expected login behavior after saving changes.

 > **💡 Tip:** If the registration option still appears after saving, refresh the browser page or open the login page in a private/incognito window to ensure you are viewing the current configuration.
