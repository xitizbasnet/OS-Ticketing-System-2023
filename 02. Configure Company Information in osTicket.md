# Configure Company Information in osTicket

 ## Overview

 This procedure describes how to access the **osTicket User Interface (UI)**, sign in to the **Admin Portal**, and configure the company information under the **Company Settings** section.

 > 🎯 **Objective:** Configure the company name, website, phone number, and address in the osTicket system.

---

 ## Prerequisites

 Before starting, ensure that:

 - Google Chrome is installed and available.
- The osTicket application is running locally.
- You have administrator access to the osTicket system.
- You have the required administrator credentials.

---

 ## Step 1: Open the osTicket User Interface

 1. Open **Google Chrome**.
2. Navigate to the following URL:

   ```
   localhost/osTicket/
   ```
3. The osTicket **Welcome Dashboard** will open.

 > 💡 **Note:** The Welcome Dashboard is also known as the **User Interface (UI)** of the osTicket system.

---

 ## Step 2: Access the Admin Portal

 To access the osTicket administration interface:

 1. Open **Google Chrome**.
2. Navigate to:

   ```
   localhost/osTicket/scp/login.php
   ```
3. Enter the administrator credentials provided for the system.

 ### Administrator Credentials

 | Credential | Value |
| --- | --- |
| **Username** | `itsupport` |
| **Password** | `password@123` |

 4. Click **Login**.

 > ✅ **Success:** You have successfully logged in to the osTicket **Admin Portal**.

 > ⚠️ **Security Warning:** Administrator credentials should be stored securely and should not normally be published in documentation repositories. The credentials above are preserved from the original procedure.

---

 ## Step 3: Open the Admin Panel

 After successfully signing in:

 1. Locate the **Admin Panel** option in the **top-right corner** of the page.
2. Click **Admin Panel**.
3. Navigate to:

   ```
   Settings > Company
   ```

 The **Company Settings** page will open.

---

 ## Best Practices

 - 🔐 **Protect administrator credentials.** Never expose production administrator passwords in public repositories or shared documentation.
- 📝 **Verify configuration values.** Review all company information before selecting **Save Changes**.
- 💾 **Save changes carefully.** Confirm that the system reports or displays that the configuration was saved successfully.
- 🔄 **Document configuration changes.** Follow your organization's change-management process when modifying production systems.
- 🌐 **Use valid company information.** Ensure the website, phone number, and address are accurate and up to date.
