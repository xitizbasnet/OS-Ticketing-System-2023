# Customize the Sign-In Page Message in osTicket

 This guide explains how to customize the message displayed on the **osTicket customer Sign-In page** by editing the **Sign-In Page** template.

 The existing message:

 > “to better serve you, we encouraged our clients to register for an account.”

 will be replaced with:

 > “to track all the tickets and the status please login to the portal.”

---

 ## 🎯 Objective

 Customize the message displayed on the osTicket Sign-In page.

 ### Before

```
to better serve you, we encouraged our clients to register for an account.
```

 ### After

```
to track all the tickets and the status please login to the portal.
```

---

 ## Prerequisites

 Before beginning, ensure that:

 - You have administrator access to the osTicket Staff Control Panel.
- You have permission to modify osTicket templates.
- osTicket is accessible through the local web server.
- You can access the **Settings** and **User** configuration areas.

---

 # Step 1: Open the osTicket Settings

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/scp/settings.php
```

 3. Sign in with an administrator account if prompted.
4. Go to **Settings**.

---

 # Step 2: Open User Settings

 1. From the **Settings** area, locate **User**.
2. Open the **User** settings.
3. Under the User settings, locate **Templates**.
4. Click **Templates**.

 > **Note:** The Templates section contains multiple templates used throughout the osTicket user interface.

---

 # Step 3: Open the Sign-In Page Template

 1. Review the available templates.
2. Locate the:
    **Sign-In Page**
    template.
3. Click **Sign-In Page** to open the template editor.

---

 # Step 4: Modify the Sign-In Page Message

 Locate the existing message in the template.

 ### Before

```
to better serve you, we encouraged our clients to register for an account.
```

 Replace it with:

 ### After

```
to track all the tickets and the status please login to the portal.
```

 Review the content to ensure that only the intended message has been changed.

---

 # Step 5: Save the Changes

 After editing the template:

 1. Review the updated content.
2. Click **Save Changes**.
3. Wait for the configuration to be saved successfully.

---

 # Step 6: Verify the Updated Sign-In Page

 After saving the template:

 1. Open **Google Chrome**.
2. Navigate to:

```
localhost/osTicket/login.php
```

 3. Go to the **Sign In** option.
4. Review the message displayed on the Sign-In page.

---

 ## 💡 Best Practices

 - **Preview or verify the change:** Always check the actual Sign-In page after modifying a template.
- **Keep messages concise:** Sign-In page instructions should be short and easy for users to understand.
- **Maintain consistent terminology:** Use the same terms, such as _ticket_, _status_, and _portal_, throughout your customer-facing documentation.
- **Test after saving:** Refresh the browser or use a private/incognito window if the old message continues to appear.
- **Document template changes:** Record customer-facing template modifications as part of your IT configuration documentation.

 > **Tip:** If the old message continues to appear after saving, refresh the page and clear any browser cache that may be displaying an older version of the page.

 > ⚠️ **Warning:** The **Sign-In Page** template controls customer-facing content. Avoid modifying template code or placeholders unless you understand their purpose, as unintended changes may affect the login page layout or functionality.
