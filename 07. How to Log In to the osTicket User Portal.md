 # 🔐 How to Log In to the osTicket User Portal

 This guide explains how a registered user can log in to the **osTicket user portal**, access their dashboard, view ticket information, and update their profile and account credentials.

---

 ## 🌐 1. Open the osTicket User Portal

 1. Open the **Google Chrome** browser.
2. Enter the following URL in the address bar:

```
localhost/osTicket/login.php
```

 3. Press **Enter** to open the osTicket user portal.

---

 ## 🔑 2. Select the Sign In Option

 On the osTicket portal:

 1. Click the **Sign In** option located at the **top-right corner** of the page.

---

 ## 👤 3. Enter User Credentials

 Enter the user's credentials:

 | Field | Value |
| --- | --- |
| **Username** | `dilip@osticket.com` |
| **Password** | `password@123` |

3. Click the **Sign In** button.

 > \[!NOTE\]\
>  The credentials above correspond to the local user account created and registered in the previous procedure.

---

 ## ✅ 4. Verify Successful Login

 After a successful login, the user will be redirected to their dashboard.

 The dashboard will display the user's name:

```
dilip
```

 The user can now access their osTicket account and view their available information.

---

 ## 🎫 5\. View Ticket Details

 From the user dashboard, the user can see their **ticket details and information**.

 This allows the user to review tickets that have been submitted through the osTicket system.

---

 ## 👤 6. Update User Profile

 The user can update their profile information as required.

 ### Contact Information

 Under **Contact Information**, the user can update:

 | Field |
| --- |
| **Email Address** |
| **Full Name** |
| **Phone Number** |

Enter or modify the information as necessary.

---

 ## 🔐 7. Update Access Credentials

 Under **Access Credentials**, the user can update their password.

 The available fields are:

 | Field |
| --- |
| **Current Password** |
| **New Password** |
| **Confirm New Password** |

> \[!TIP\]\
>  Use a strong password when changing the account password. Avoid using easily guessable information such as names, phone numbers, or common passwords.

---

 ## 💾 8. Save the Updated Information

 After updating the required profile or access credential information:

 1. Review the changes.
2. Click the **Update** button.

 The updated information will then be saved to the user's account.

 ## 💡 Best Practices

 - Always verify that you are using the correct osTicket portal URL.
- Do not share user credentials with other users.
- Use a strong and unique password.
- Keep contact information up to date.
- Verify the **Current Password**, **New Password**, and **Confirm New Password** fields before updating credentials.
- Click **Update** after making profile changes.
- Never store real production passwords in publicly accessible IT documentation.

 > \[!CAUTION\]\
>  `password@123` is shown here as the example/local password from the procedure. For a production environment, use a strong, unique password and never publish real credentials in a GitHub repository.
