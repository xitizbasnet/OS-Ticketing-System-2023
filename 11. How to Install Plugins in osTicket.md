# How to Install Plugins in osTicket

 ## 📋 Overview

 This document explains how to download, install, activate, and verify plugins in **osTicket**.

 The process includes:

 1. Downloading plugins from the osTicket website.
2. Extracting the downloaded plugin package.
3. Copying the plugins to the osTicket plugins directory.
4. Opening the osTicket Plugin Management page.
5. Installing each plugin.
6. Setting the plugin status to **Active**.
7. Saving the configuration.
8. Verifying that all plugins are installed and active.

---

 ## 🌐 1. Download osTicket Plugins

 Open **Google Chrome** and go to the following URL:

```
https://osticket.com/download/
```

 Scroll down and look for the **Plugins** section.

 Click **Plugins**.

---

 ## 📦 2. Select the osTicket Version

 Choose the appropriate osTicket version.

 For example:

```
osTicket v1.18
```

 > 💡 **Tip:** Select the plugin version that is compatible with the version of osTicket installed in your environment.

---

 ## ☑️ 3. Select the Plugins

 Select all the available plugin options for download.

 The available plugins include the following.

 ### Authentication :: OAuth2

 **Requires:** osTicket v1.17.x

 Provides OAuth2 authentication and authorization (**Modern Email Authentication**) support.

---

 ### 2FA :: Authenticator

 **Requires:** osTicket v1.15+

 Provides 2 Factor Authentication using an Authenticator App. More

---

 ### Audit :: Audit Log

 **Requires:** osTicket v1.14+

 Allows Administrators to keep track of what Agents and Users are doing in the helpdesk. More

---

 ### Authentication :: Password Policy

 **Requires:** osTicket v1.15

 Allows Administrators to enforce custom requirements for Agents’ and Users’ passwords in the helpdesk. More

---

 ### Authentication :: HTTP Pass-Through

 Allows for the HTTP server (**Apache or IIS**) to perform the authentication of the user.

---

 ### Authentication :: LDAP and Active Directory

 Provides a configurable authentication backend which works against **Microsoft Active Directory** and **OpenLdap servers**.

---

 ### Storage :: Attachments on the Filesystem

 Store attachments in a folder on the filesystem instead of the database.

---

 ### Storage :: Attachments in Amazon S3

 **Requires:** osTicket v1.17.x

 Store attachments in S3 instead of the database.

---

 ## ⬇️ 4. Download All Plugins

 Tick the checkbox for all of the plugins.

 After selecting all the plugins, click the **Download** button.

 > ✅ **Best Practice:** Before downloading, verify that the selected plugins are compatible with your installed osTicket version.

---

 ## 📁 5. Open the Download Folder

 Go to your computer's **Downloads** folder.

 You should see a ZIP file similar to:

```
osTicket-plugin
```

---

 ## 📦 6. Extract the Plugin Package

 Extract the downloaded ZIP file using **WinRAR**.

 After extracting the file, copy the extracted plugin folder.

---

 ## 📂 7. Copy the Plugins to the osTicket Plugins Directory

 Navigate to the following directory:

```
C:/xampp/htdocs/osTicket/include/plugins
```

 Paste the copied plugin folder into this directory.

 The plugins should now be available to osTicket.

 > 📝 **Note:** Make sure the plugin files and folders are copied into the correct `include/plugins` directory for the osTicket installation.

---

 ## 🌐 8. Open the osTicket Plugin Management Page

 Open **Google Chrome** and go to:

```
localhost/osTicket/scp/plugins.php
```

 Go to the menu:

```
Manage > Plugins
```

---

 ## 🔌 9. Review the Plugin Dashboard

 The **Plugins** dashboard displays the plugins available to osTicket.

 Initially, there may be no plugins installed.

 To install the plugins, click the:

 **Add New Plugins**

 button.

---

 ## ➕ 10. Add New Plugins

 After clicking **Add New Plugins**, you can see the plugin details for the plugins that were copied to:

```
C:/xampp/htdocs/osTicket/include/plugins
```

 The available plugins should now be displayed.

---

 ## ⚙️ 11. Install the Plugins

 Install the plugins one by one.

 For example, locate the plugin:

```
Help Desk Audit
```

 You can see the **Install** button on the left side of the plugin name.

 Click **Install**.

---

 ## 🟢 12. Activate the Plugin

 After installing the plugin, configure its status.

 Under **Status**, choose:

```
Active
```

 Then click:

 **Save Changes**

 > ✅ **Success:** The plugin has been installed and activated.

---

 ## 🔁 13. Install the Remaining Plugins

 Repeat the same process for all the plugins.

 For each plugin:

 1. Click **Install**.
2. Set the **Status** to **Active**.
3. Click **Save Changes**.
4. Continue with the next plugin.

 Continue until all required plugins have been installed.

---

 ## 🔍 14. Verify the Installed Plugins

 After installing all the plugins, open Google Chrome and go to:

```
localhost/osTicket/scp/plugins.php
```

 Go to:

```
Manage > Plugins
```

 The Plugin Management dashboard should now display all the plugins that have been installed.

 Verify that the status of each installed plugin is:

```
Active
```

---

 ## ✅ Expected Result

 After completing the installation:

 - All selected plugins are installed.
- All required plugins are displayed in the **Plugins** dashboard.
- The plugins are configured with the status **Active**.
- The plugins are ready to be used by osTicket.

 ## ⚠️ Troubleshooting and Best Practices

 ### Plugin Does Not Appear

 If a plugin does not appear under **Add New Plugins**:

 - Verify that the plugin was extracted correctly.
- Verify that the plugin was copied to:

```
C:/xampp/htdocs/osTicket/include/plugins
```

 - Verify that the plugin is compatible with your osTicket version.
- Refresh the **Manage \> Plugins** page.

 ### Plugin Cannot Be Activated

 If the plugin cannot be activated:

 - Check the plugin's version requirements.
- Confirm that the required dependencies are installed.
- Review the osTicket and web-server logs.
- Verify the plugin files are in the correct directory.

 ### 🔐 Security Best Practice

 Only install plugins from trusted sources and verify compatibility before installing them in a production osTicket environment.

 For authentication-related plugins such as **LDAP**, **Active Directory**, **OAuth2**, and **2FA**, test the configuration in a non-production environment before deployment.
