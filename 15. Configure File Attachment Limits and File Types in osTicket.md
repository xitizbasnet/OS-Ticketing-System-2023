# Configure File Attachment Limits and File Types in osTicket

 This guide explains how to configure **file attachment settings** in osTicket, including the maximum attachment size and the types of files users are allowed to attach.

 > **Audience:** Interns, L1/L2 Support Engineers, and Administrators\
>  **Platform:** osTicket\
>  **Access:** osTicket Staff Control Panel (SCP)

 ## Prerequisites

 Before beginning, ensure that:

 - You have access to the osTicket Staff Control Panel.
- You have the required administrator permissions to modify system settings.
- osTicket is accessible through the local web server.

 ## Step 1: Open the osTicket Staff Control Panel

 1. Open the **Google Chrome** browser.
2. Navigate to the following URL:

```
localhost/osTicket/scp/login.php
```

 3. Sign in using your osTicket administrator credentials.

 > **Note:** The URL above assumes that osTicket is installed locally and is accessible through `localhost`.

 ## Step 2: Open System Settings

 1. From the osTicket Staff Control Panel, go to:
    **Settings \> System**
2. Scroll down to the bottom of the page.
3. Locate the following option:
    **Ticket Attachment Setting: Config**

 ## Step 3: Configure Ticket Attachments

 1. Click the **Config** button next to **Ticket Attachment Setting**.
2. After clicking the **Config** button, a pop-up dashboard titled:
    **Field Configuration - Issue Details**
    will appear.
3. Configure the attachment settings as follows:

 | Setting | Configuration |
| --- | --- |
| **Enable Attachments** | Enable **Attachments, regardless of channel** |
| **Maximum File Size** | **2 MB** |
| **Restrict by File Type** | **Audio and Music, Video Files, Archives** |
| **Additional File Type Filters** | `.pdf, .png` |

### Attachment Configuration

 Enable the following option:

 > ☑ **Enables attachments, regardless of channel**

 Set the maximum attachment size to:

```
2 MB
```

 Under **Restrict by File Type**, select:

 - 🎵 **Audio and Music**
- 🎬 **Video Files**
- 📦 **Archives**

 Under **Additional File Type Filters**, enter:

```
.pdf,.png
```

 ## Step 4: Save the Configuration

 After configuring the required settings:

 1. Review the attachment configuration.
2. Click **Save**.

 The attachment restrictions will then be applied to the osTicket configuration.

 > ⚠️ **Warning:** Changing attachment restrictions can affect what users are able to upload to tickets. Verify the configuration carefully before saving it in a production environment.

 ## Recommended Configuration Summary

 The final configuration should look like this:

```
Ticket Attachment Setting: Config

Enables attachments, regardless of channel: Enabled

Maximum File Size: 2 MB

Restrict by File Type:
- Audio and Music
- Video Files
- Archives

Additional File Type Filters:
.pdf,.png
```

 ## 💡 Best Practices

 - Keep the **maximum attachment size** appropriate for your organization's storage capacity.
- Restrict unnecessary file types to reduce security and storage risks.
- Review attachment policies periodically as business requirements change.
- Test the configuration with a sample ticket after making changes.
- Document any changes made to attachment restrictions for future administrators.

 > **Tip:** After saving the configuration, create a test ticket and attempt to upload both an allowed and a restricted file type to confirm that the settings are working as expected.
