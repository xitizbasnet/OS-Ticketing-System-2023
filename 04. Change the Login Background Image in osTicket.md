# 04\. Change the Login Background Image in osTicket

 ## Overview

 This procedure explains how to change the **login page background image** in osTicket.

 The procedure also covers how to remove the configuration-file permission warning by changing the `ost-config.php` file to **Read-only** before modifying the login backdrop.

 > 🎯 **Objective:** Configure a custom login background image and verify that the updated image is displayed on the osTicket Admin Login Portal.

---

 ## Prerequisites

 Before starting, ensure that:

 - Google Chrome is installed.
- The osTicket application is running locally.
- You have administrator access to the osTicket system.
- A custom background image is available for upload.
- You have access to the osTicket installation directory through Windows File Explorer.

---

 ## Step 1: Open the osTicket User Interface

 1. Open **Google Chrome**.
2. Navigate to:

   ```
   localhost/osTicket/
   ```
3. The osTicket **Welcome Dashboard** will open.

 > 💡 **Note:** The Welcome Dashboard is also known as the **User Interface (UI)**.

---

 ## Step 2: Log In to the Admin Portal

 To access the osTicket Admin Portal:

 1. Open Google Chrome.
2. Navigate to:

   ```
   localhost/osTicket/scp/login.php
   ```
3. Enter the administrator credentials:
    | Credential | Value |
   | --- | --- |
   | **Username** | `itsupport` |
   | **Password** | `password@123` |
4. Click **Login**.

 > ✅ **Success:** You have successfully logged in to the osTicket Admin Portal.

---

 ## Step 3: Open the Admin Panel

 To access the administrative settings:

 1. Click **Admin Panel** from the **top-right corner** of the menu.
2. The settings page will open.

 The URL should be:

```
localhost/osTicket/scp/settings.php
```

---

 ## Step 4: Resolve the Configuration File Permission Warning

 When the settings page opens, you may see the following alert message:

 > ⚠️ **Configuration File Warning**
>
>  **"Please change permission of config file (ost-config.php) to remove write access, e.g: chmod 644 ost-config.php"**

 This warning indicates that the `ost-config.php` configuration file currently has write access.

 ### Locate the Configuration File

 Navigate to the following location:

```
C:\xampp\htdocs\osTicket\include\ost-config.php
```

 ### Change the File to Read-Only

 1. Right-click the **`ost-config.php`** file.
2. Select **Properties**.
3. Under the **General** tab, locate **Attributes**.
4. Select the **Read-only** checkbox.
5. Click **OK**.

 > 🔐 **Best Practice:** The osTicket configuration file should not remain writable after installation and configuration. Removing write access helps protect the application's configuration from unauthorized modification.

---

 ## Step 5: Verify the Configuration Warning Is Removed

 Return to Google Chrome and refresh the following URL:

```
localhost/osTicket/scp/settings.php
```

 Verify that the configuration-file permission alert is no longer displayed.

 > ✅ **Success:** The configuration-file permission warning has been removed.

---

 ## Step 6: Navigate to the Login Backdrop Settings

 To change the login background image:

 1. Navigate to:
    **Settings \> Company \> Login Backdrop**
2. Under **Custom Logo**, locate the option to use a **Custom Backdrop**.
3. Click **Choose File**.
4. Select the custom background image from your computer.

 > 💡 **Tip:** Choose a background image with suitable dimensions and resolution for the osTicket login page.

---

 ## Step 7: Save the Login Backdrop

 After selecting the custom backdrop:

 1. Click **Save Changes**.
2. Select the **Both** radio button.
3. Click **Save Changes** again.

 > ℹ️ **Note:** The **Both** option is selected according to the original configuration procedure.

---

 ## Step 8: Log Out

 After saving the new login backdrop:

 1. Click **Logout**.
2. You will be returned to the login page.

---

 ## Step 9: Perform a Hard Refresh

 To ensure that the browser loads the newly configured background image:

 1. Open Google Chrome.
2. Press:

   ```
   Ctrl + F5
   ```

 This performs a hard refresh and forces the browser to reload the page resources.

---

 ## Step 10: Open the Admin Login Portal

 Navigate to:

```
localhost/osTicket/scp/login.php
```

 Refresh the page if necessary.

 The custom background image should now be displayed on the osTicket login page.

 > ✅ **Success:** The login background image has been successfully changed.

 ## Best Practices

 - 🔐 **Protect `ost-config.php`:** Keep the configuration file protected from unauthorized write access.
- 🖼️ **Optimize the backdrop:** Use a suitably sized and optimized image to avoid unnecessarily slow login-page loading.
- 💾 **Keep a backup:** Back up the existing configuration and image before making changes.
- 🔄 **Clear cached content:** Use **Ctrl + F5** when browser caching prevents the new image from appearing.
- 🧪 **Verify the result:** Always check the actual login portal after changing the backdrop.
- 🔑 **Protect administrator credentials:** Do not publish production administrator passwords in GitHub repositories or other publicly accessible documentation.

 > ⚠️ **Security Note:** The administrator credentials are retained because they were included in the original procedure. For production documentation, replace them with a secure reference to your organization's password manager or secret-management system.
